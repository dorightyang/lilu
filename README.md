# 李录资料整理

本仓库整理李录公开演讲、采访、对谈与相关视频文字稿，参考 [dorightyang/duan](https://github.com/dorightyang/duan) 的目录方式组织。

目前仓库只放整理后的终稿与字幕，不放原始视频大文件：
- `文稿-精校.md`：人工/模型整理后的可读终稿
- `字幕-中文.srt`：中文字幕
- `字幕-双语.srt`：双语字幕
- `字幕-英文.srt`：英文基准字幕

目录入口：
- [【文章目录】/2-对外演讲、采访](./【文章目录】/2-对外演讲、采访/)

说明：
- 2015 北大 B 站视频已人工判定为低质量 AI 生成内容，未纳入本仓库。
- 2012 与 2021 的双语字幕视频采用 `YouTube .en.srt` 作为时间轴基准，再生成中文/双语字幕。
